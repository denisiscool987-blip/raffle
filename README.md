# Lucky Draw Raffle

A simple, beautiful raffle / giveaway web app built with pure **HTML**, **CSS**, and **JavaScript**.  
No frameworks, no backend, no tracking — everything runs in your browser.

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Made with](https://img.shields.io/badge/made%20with-HTML%20%2B%20CSS%20%2B%20JS-purple)

## Features

- Add participants (supports bulk paste — commas, semicolons, or new lines)
- Add prizes
- One-click random draw using Fisher-Yates shuffle
- Animated winner reveal with medals for top 3
- Copy results to clipboard
- Fully responsive
- Dark modern UI with soft animated background

## How to use

1. Open `index.html` in any modern browser  
   **or** host the folder on GitHub Pages / Netlify / any static host.
2. Type names into the **Participants** box and press Enter (or paste a list).
3. Type prizes into the **Prizes** box the same way.
4. Click **Draw Winners**.
5. Share the results or hit **New Draw** to try again.

## File structure

```
lucky-draw-raffle/
├── index.html      # Main page
├── style.css       # Styles
├── script.js       # Logic
└── README.md       # This file
```

## Deploy on GitHub Pages

1. Create a new repository.
2. Upload these four files (or push via git).
3. Go to **Settings → Pages**.
4. Set source to `main` branch / root.
5. Your raffle will be live at `https://<username>.github.io/<repo-name>/`.
